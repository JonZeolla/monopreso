# Guardrails for AI Coding

Generative AI is quickly becoming a default part of the software development lifecycle. Faster delivery can also increase security risk, operational fragility, and decisions that are difficult to review or audit after the fact.

This session focuses on AI coding guardrails: practical, developer-friendly controls that help teams adopt coding assistants with confidence while maintaining strong security, governance, and assurance. We walk through four cumulative maturity levels for agentic coding controls:

1. **Level 1: Crawl — Basic Steering.** Set expectations through project context files, rules, and instruction layers.
2. **Level 2: Walk — Agent Reviewing Agents.** Use specialized review and context-injection agents to deliver the relevant requirements, approved patterns, and constraints when they matter.
3. **Level 3: Run — Policy-as-Code Guardrails.** Enforce deterministic security, quality, and compliance policy in pull requests and CI/CD with audit-ready evidence.
4. **Level 4: Fly — Continuous Improvement.** Improve context, skills, and guardrails through feedback, evaluations, bounded updates, and held-out promotion gates.

The goal is not to slow agentic development down. It is to build a control system that can keep up.
