# Cutting-room floor

Slides removed from the SANS CSE / CSA Birmingham talk during the August 2026
editing pass, collected so they can be reviewed and pulled back if wanted.

This is **not a talk**. There is no narrative order — slides are grouped by when
they were cut. Nothing here is imported by either live deck, and every macro it
calls still lives in `modules/`, so restoring a slide means adding its call back
to a deck, not recovering deleted code.

    cd presentations/2026-08-cut-slides && task start

Sections:

1. **Cut in the CSA mirror** (2026-08-20) — the 17 slides CSA lost when it
   adopted the SANS running order.
2. **Cut earlier in the editing pass** (2026-08-17 → 19) — the guardrail
   spectrum, policy-as-code history, the "should you?" decision slides, the
   two-kinds/composition pair, CI/CD enforcement, and server-side wiring.
3. **Cut when SANS took the CSA order** (2026-08-20) — the original SANS CSE
   maturity model (crawl/walk/run/fly) and its context-refinement material,
   including SkillOpt evaluation design and the research landscape.
